# Finance Tracker – Django Web Application

## Project Overview
Finance Tracker is a web-based application developed using Django to help users manage and track their personal finances. Users can record income and expenses, monitor savings, and view financial information through a dashboard.

## Features
- User authentication and login
- Income and expense management
- Add, update, and delete transactions
- Categorize financial transactions
- Financial dashboard
- Track income, expenses, and savings
- Generate PDF reports

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Bootstrap

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/barikchandrasekhar/Finance-Tracker-Django.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Finance-Tracker-Django
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment (Windows):

   ```bash
   venv\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Apply migrations:

   ```bash
   python manage.py migrate
   ```

7. Create a superuser:

   ```bash
   python manage.py createsuperuser
   ```

8. Start the development server:

   ```bash
   python manage.py runserver
   ```

9. Open `http://127.0.0.1:8000/` in your browser.
